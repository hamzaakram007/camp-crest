# Camp Crest

Private friend-code summer camp builder for kids (~6–10). Create or join a camp, decorate cabin/grounds/dock/trails, gather soft badges, and put on a short evening show — no open stranger lobby.

## Play

```bash
npm install
npm run dev
```

## MVP features

- **Create camp** — get a shareable friend code
- **Join with code** — simulated codes (`CREST-DEMO`, `PINE-4821`, `LAKE-7730`) or any `WORD-####`
- **Build / decorate** — place props on a bounded camp map
- **Gather** — collect leaves, shells, pinecones to unlock décor
- **Camp show** — pick 2–5 props for a short evening skit (earns a Camp Star)

Progress saves in `localStorage` on this device.
