# Camp Crest

Private friend-code summer camp builder for kids (~6–10). Create or join a camp, decorate cabin/grounds/dock/trails/stage, gather soft badges, and put on a short evening show — no open stranger lobby.

## Play

```bash
npm install
npm run dev
```

Live: https://camp-crest.vercel.app

## Features (v2)

- **Richer build** — cabin porch, rugs, hammocks, totems, kayaks, trail tents, stage mics/drums, zone filters
- **Friend codes + share links** — copy a code *or* a share URL that carries the cabin layout across browsers
- **Soft badges** — leaves, shells, pinecones, berries, feathers → décor unlocks; Camp Stars & Show Ribbons from shows
- **Evening shows** — titled skits, audience reactions, applause meter, soft achievement chips
- **Outdoorsy mobile UI** — pine dusk palette, fireflies, lake shimmer, safe-area padding

Progress saves in `localStorage` on this device. Cross-browser co-build uses the **Share invite link** (camp snapshot in the URL).
